# 🤝 Friendship Webpage Template

A responsive, customizable HTML/CSS/JavaScript template designed to create personalized friendship showcase websites, digital memory cards, and interactive scrapbooks.

---

## 🌟 Key Features

* **🎨 Modern Visual Design:** Clean layouts with smooth gradient accents, dynamic animations, and responsive typography.
* **📱 Fully Responsive:** Optimized across desktop, tablet, and mobile viewports.
* **🖼️ Interactive Memory Showcase:** Custom card containers for photos, personalized messages, and memory highlights.
* **✨ Smooth UI Mechanics:** Lightweight JavaScript interactions for floating animations and smooth scrolling.
* **⚡ One-Click Deployment:** Ready for hosting on Netlify, Vercel, or GitHub Pages.

---

## 🛠️ Tech Stack

* **Front-End:** HTML5, CSS3 (Flexbox/Grid, CSS Animations), Modern JavaScript (ES6+)
* **Icons & Fonts:** FontAwesome, Google Fonts
